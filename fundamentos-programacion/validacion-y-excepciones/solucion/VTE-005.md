# Solución


| Función                      | Parámetros | Retorno | Responsabilidad |
|------------------------------|---|---|---|
| `validar_panel`              | `panel` | `str` | Verificar las dimensiones, la estructura y los valores del panel. |
| `contar_vecinas`             | `panel`, `fila`, `columna` | `int` | Contar las vecinas encendidas de una posición. |
| `construir_siguiente_estado` | `panel` | `list` | Construir un nuevo panel aplicando la regla de actualización. |
| `siguiente_estado`           | `panel` | `tuple` | Coordinar la validación y construcción del siguiente estado, comunicando posibles errores. |
| `mostrar_panel`              | `panel` | `None` | Mostrar el contenido de un panel. |
| `demostrar`                  | Ninguno | `None` | Ejecutar los casos de demostración. |
| `probar_solucion`            | Ninguno | `None` | Verificar la simultaneidad de los cambios y la independencia del panel original. |


| Función                      | Descripción de la lógica                                                                                                                                                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `validar_panel`              | Comprueba que el panel sea una lista, que sus dimensiones estén dentro de los límites permitidos, que todas las filas tengan igual longitud y que sus elementos sean enteros con valores `0` o `1`. Devuelve un mensaje si encuentra un error. |
| `contar_vecinas`             | Examina las posiciones inmediatamente superior, inferior, izquierda y derecha de una luz. Verifica que cada posición exista y suma los valores de las vecinas encendidas.                                                                      |
| `construir_siguiente_estado` | Recorre todas las posiciones del panel original, cuenta sus vecinas encendidas y asigna `1` si tiene exactamente dos; en caso contrario, asigna `0`. Construye y devuelve un panel nuevo.                                                      |
| `siguiente_estado`           | Coordina la solución: primero valida el panel y, si es válido, construye el siguiente estado. Devuelve el resultado y un mensaje que indica posibles errores.                                                                                  |
| `mostrar_panel`              | Recorre las filas y columnas del panel e imprime sus valores, conservando su disposición rectangular.                                                                                                                                          |
| `demostrar`                  | Recorre un conjunto de paneles definidos en el programa, ejecuta la solución para cada uno y muestra el siguiente estado o el mensaje de error correspondiente.                                                                                |
| `probar_solucion`            | Ejecuta pruebas con resultados conocidos para comprobar que la regla se aplica correctamente, que los cambios son simultáneos y que el panel original permanece independiente del resultado.                                                   |

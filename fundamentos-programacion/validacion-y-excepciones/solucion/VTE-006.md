# Interfaces

| Unidad                   | Parámetros                                                                | Retorno                         | Responsabilidad                                                      |
|:-------------------------|:--------------------------------------------------------------------------|:--------------------------------|:---------------------------------------------------------------------|
| `validar_reaccion()`     | `mensajes: dict`, `usuarios: list`, `identificador: int`, `usuario: str`  | `str`                           | Verifica las condiciones para agregar una reacción a un mensaje.     |
| `agregar_reaccion()`     | `mensajes: dict`, `usuarios: list`, `identificador: int`, `usuario: str`  | `tuple` (`int` o `None`, `str`) | Incorporar una reacción válida y retornar el resultado.              |
| `gestionar_reacciones()` | `mensajes: dict`, `usuarios: list`                                        | `None`                          | Gestionar las entradas, tratar excepciones y mostrar los resultados. |

# Casos de prueba

| Identificador | Usuario            | Resultado esperado                          |
|:--------------|:-------------------|:--------------------------------------------|
| `"hola"`      | No se solicita     | Error de conversión                         |
| `999`         | `"yei_lo"`         | El mensaje no existe                        |
| `101`         | `"desconocido"`    | Usuario no registrado                       |
| `101`         | `"la_mon"`         | No puede reaccionar a su propio mensaje     |
| `205`         | `"la_mon"`         | Ya reaccionó al mensaje                     |
| `101`         | `"yei_lo"`         | Operación aceptada; cantidad: 1             |
| `101`         | `"yei_lo"`         | Reacción repetida; cantidad conservada en 1 |
| `101`         | `"nino_maravilla"` | Operación aceptada; cantidad: 2             |
| `FIN`         | No se solicita     | Finaliza                                    |

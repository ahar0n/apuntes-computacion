# Ejercicio: Resolución de problemas

RP-001. Identificación y lectura.

1. Para el problema «calcular el área de un rectángulo», identifique el problema, una instancia, entradas, salida y relación entrada-salida.
2. Clasifique cada elemento del diagrama del precio final como inicio o fin, entrada, proceso o salida.
3. Ejecute manualmente el algoritmo del descuento con $P=120$ y $d=15$. Registre los valores en una tabla de seguimiento.

RP-002. Especificación y diseño.

1. Especifique el problema de calcular el perímetro de un rectángulo. Declare las entradas, la salida, las restricciones y la relación entrada-salida.
2. Diseñe y represente mediante un diagrama de flujo un algoritmo que convierta una masa expresada en kilogramos a gramos.
3. Diseñe un algoritmo que calcule el promedio de tres números. Prepare una tabla de seguimiento para una instancia.
4. Complete la especificación ambigua «calcular la nota final» mediante preguntas pertinentes.

RP-003. Prueba, diagnóstico y comparación

1. Diseñe los casos de prueba representativos y límite para el algoritmo que calcula el área de un rectángulo con lados no negativos. Añada datos no admitidos para revisar la delimitación del dominio, sin ejecutarlos como instancias del algoritmo.
2. Revise un diagrama de los ejercicios RP-002-2 o RP-002-3 usando estos criterios: correspondencia con la especificación, símbolos consistentes, orden de las operaciones y uso de datos previamente definidos.

RP-004. Integración

1. Especifique, diseñe, represente y pruebe un algoritmo que calcule el total de una compra formada por $n$ productos con el mismo precio unitario. Distinga explícitamente las tres etapas y señale qué aspectos quedarían para la implementación.
